# 数据投放目录

把你的仪器导出工作簿直接放在这里，然后运行 `adsorp.bat run`（或在项目根目录双击
`adsorp.bat`，默认就是 `run`）。

## 命名约定

三类实验各取一个文件，文件名包含下列关键词即可（大小写、前后缀不限）：

| 实验 | 文件名需包含 | 示例 |
|---|---|---|
| 等温线 | `等温` | `2026-10-21_等温.xlsx` |
| 动力学 | `动力学` | `2026-10-21_动力学.xlsx` |
| 吸附边 | `吸附边` | `2026-10-21_吸附边.xlsx` |

- 只做其中一两类也可以，缺的那类会在运行日志和报告里提示「未找到」。
- 同类有多个文件时，只取文件名排序第一个，并打印警告列出被忽略的文件。
- 文件必须是 `.xlsx`（`.xls` 请先另存为 `.xlsx`）。
- 不要在这里建子目录：脚本只扫描本层。

## 其他放法

- **放项目根目录**：脚本在 `data/` 里找不到可识别的表时，会自动回退到项目根目录，
  所以把 Excel 直接丢进 `分析/` 也能跑。
- **用模板**：数据已经整理成长表时，不必按文件名约定，直接
  `adsorp.bat run --template 你的表.xlsx`。
- **指定任意目录**：`adsorp.bat run --data-dir D:\某批数据`。

本目录只放输入，不放结果；结果一律写到 `output/`。
