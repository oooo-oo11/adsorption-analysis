# 数据投放目录

把 Excel 直接放在这里，不需要改文件名，然后双击 `adsorp.bat`（或在项目根目录运行
`adsorp.bat run`）。目录里有几个文件就读几个。

## 支持两种表

| 形态 | 认法 | 说明 |
|---|---|---|
| 仪器导出的原始工作簿 | 有 `样品名称` + `实测荧光值` 表头 | 软件按表内内容判断是等温线 / 动力学 / 吸附边 |
| 整理好的长表（模板） | 有 `Data` 表且表头含 `exp` | 走模板分支，可带固液比等元数据 |

两类可以混放。同时存在时优先用原始工作簿，日志会提示；想强制用模板就加 `--template`。

## 实验类型怎么判断（不靠文件名）

1. 先看表名与表头上方的标题：写了「等温 / 动力学 / 吸附边」（或英文 isotherm /
   kinetics / edge）就按写的来；
2. 标题里没有线索时看哪一列真正有数据：`反应时间/h` 有值 → 动力学，
   `目标 pH` 有值 → 吸附边，两者都没有 → 等温线。

运行日志第一行会把每个文件的判定结果打出来，例如：

```
[1/5] 读取数据：...\data
      a.xlsx → 等温线
      b.xlsx → 动力学
```

判错了就在标题或表名里写清楚，或者干脆整理成模板避开这一步。

## 其他放法

- **放项目根目录**：`data/` 里没有 Excel 时自动回退到项目根目录，
  所以把文件直接丢进项目文件夹也能跑。
- **用模板**：`adsorp.bat run --template 你的表.xlsx`。
- **指定任意目录**：`adsorp.bat run --data-dir D:\某批数据`。

先跑 `adsorp.bat check --template 你的表.xlsx` 看行数、分组、缺列，比直接 `run` 更好定位问题。

## 注意

- 只扫描本层，不递归子目录；Excel 生成的 `~$xxx.xlsx` 锁文件会自动跳过。
- 一个工作簿装一类实验最稳妥；同一文件里混两类时，整份会按判出来的那类处理。
- 本目录只放输入，不放结果；结果一律写到 `output/`。
