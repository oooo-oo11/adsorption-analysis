吸附数据分析工具 · 开始使用
================================================================

不用安装 Python。把整个文件夹解压到任意位置（路径别带奇怪符号），
双击 adsorp.bat 就行。

三步
----------------------------------------------------------------
1. 把你的 Excel 放进 data 文件夹
   不用改文件名，放几个都行；整理好的长表（模板）也可以放这里。

2. 双击 adsorp.bat
   窗口里会滚动打印进度，大约 20~60 秒。

3. 跑完会自动打开 output\报告.html
   图、表、汇总都在 output 里：
     output\报告.html      图文报告（单个文件，可直接转发）
     output\figures\       每张图的 PNG（300 dpi）与 PDF（矢量）
     output\tables\        每个表的 CSV
     output\结果汇总.xlsx   全部结果

想先看看效果
----------------------------------------------------------------
把 templates\吸附数据模板.xlsx 复制一份到 data 文件夹，再双击 adsorp.bat，
就能跑出一套完整结果（里面有编好的示例数据：两条等温线、一组动力学、
一条 pH 边）。看完把那份复制品删掉即可。

表要怎么填
----------------------------------------------------------------
打开 templates\吸附数据模板.xlsx，第一张 README 表里写了每一列的含义；
也可以在程序里跑 adsorp.bat template 重新生成一份空白模板。
列名、单位、换算公式都在那张表里，不用查别的文档。

出错了怎么办
----------------------------------------------------------------
1. 先看窗口里最后几行提示，多数问题会直接说明原因
   （例如「未解析到数据」「缺 反应时间/h」）。
2. 详细日志在 output\run.log。
3. 还是不行，把 run.log 连同那张 Excel 一起发给提供软件的人。

第一次运行被 Windows 拦下
----------------------------------------------------------------
- 若提示「Windows 已保护你的电脑」或「已阻止此文件」：点「更多信息」→
  「仍要运行」。这是压缩包从网上下载后附带的标记，不是病毒。
- 想一次性去掉：右键 zip → 属性 → 勾选「解除锁定」→ 确定，再解压。

几条要注意的
----------------------------------------------------------------
- 别删 python 文件夹：里面是软件自带的 Python，删了就跑不起来。
- 同一个数据文件夹里，一个工作簿装一类实验最稳妥；混装时整份会按
  判出来的那一类处理（日志里会写「文件名 → 等温线/动力学/吸附边」）。
- 每次运行会整目录覆盖 output，手工放进 output 的东西会丢。
- 只支持 64 位 Windows 10 及以上。
- 完整说明见 README.md（写得比较细，需要时再翻）。
