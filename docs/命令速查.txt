start output\报告.html

rem 只重绘图与报告，不重跑拟合（调图版式时用）
adsorp.bat run --reuse

rem 指定别的数据目录
adsorp.bat run --data-dir D:\某批数据

rem 用填好的模板（含固液比等元数据）
adsorp.bat run --template templates\吸附数据_已填示例.xlsx

rem 只校验模板，不拟合（几秒）
adsorp.bat check --template templates\吸附数据_已填示例.xlsx

rem 生成空白模板（默认写到 templates\吸附数据模板.xlsx）
adsorp.bat template
