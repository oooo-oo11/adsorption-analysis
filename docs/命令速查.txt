吸附分析 · 命令速查
================================================================

启动方式：
  双击 adsorp.bat           （多份 Excel 时输入编号选一份，0 取消；单文件直跑）
                           （分析成功后自动打开报告，取消不打开旧报告）
  .\adsorp.bat  run         （PowerShell，注意前面的 .\）
  adsorp.bat    run         （cmd）

  .\adsorp.ps1  run         原生 PowerShell 版本，但需先放开执行策略（见文末）

----------------------------------------------------------------
日常
----------------------------------------------------------------
cd "C:\path\to\分析"                  # PowerShell 用 cd
.\adsorp.bat                           # 选择 data\ 中的一份 Excel
.\adsorp.bat run                       # 整目录：仪器表合并；仅模板时取最新一份
Invoke-Item output\报告.html           # 打开报告（cmd 用 start）

.\adsorp.bat run --reuse               # 只重绘图与报告，不重跑拟合
.\adsorp.bat run --ipd-stages 3        # 颗粒内扩散分三段（默认两段，需 ≥10 个时间点）

----------------------------------------------------------------
换数据
----------------------------------------------------------------
# 方式 1：工作簿丢进 data\（按表内内容自动判断等温/动力学/吸附边，不用改文件名）
.\adsorp.bat                           # 多文件时选择一份
.\adsorp.bat run                       # 按原有规则处理整个目录，不弹选择

# 方式 2：整理成长表模板
.\adsorp.bat template                                    # 生成空白模板
.\adsorp.bat check  --template templates\吸附数据模板.xlsx  # 只校验，几秒
.\adsorp.bat run    --template templates\吸附数据模板.xlsx

# 方式 3：任意目录
.\adsorp.bat run --data-dir D:\某批数据

# 方式 4：把当前已解析的数据导出成模板，改完再跑
.\adsorp.bat export --out 示例.xlsx

----------------------------------------------------------------
排错
----------------------------------------------------------------
.\adsorp.bat check --template 你的表.xlsx    # 先看行数/分组/缺列
双击 adsorp.bat 后结论会留在运行窗口里        # 可查看数据质量提示、模型触界等
output\run.log 里也有同一份完整日志            # 每次 run 自动生成，排错时发这个

找不到 Python：设置环境变量指向解释器
  $env:ADSORP_PYTHON = "C:\Python313\python.exe"     # PowerShell
  set ADSORP_PYTHON=C:\Python313\python.exe           # cmd

依赖缺失：
  pip install -r requirements.txt

----------------------------------------------------------------
关于 PowerShell 执行策略
----------------------------------------------------------------
Windows 默认 Restricted，.ps1 一律不让跑，报「禁止运行脚本」。
【最省事】改用 .\adsorp.bat —— .bat 不受执行策略限制，效果完全相同。

确实想用 .ps1，二选一：
  1) 只放开当前用户（一次即可，可随时改回 Undefined）
       Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
     还原：Set-ExecutionPolicy -Scope CurrentUser Undefined
  2) 每次都绕过（不改系统设置）
       powershell -ExecutionPolicy Bypass -File .\adsorp.ps1 run
